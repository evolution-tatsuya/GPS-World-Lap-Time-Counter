# GPS Lap Timer（スマホ単体版）

スマホ1台で動くGPSラップタイマー。PC・専用アプリ不要。車に載せて走行タイムを計測します。

## 公開URL

GitHub Pages で公開:

```
https://evolution-tatsuya.github.io/GPS-World-Lap-Time-Counter/gps/
```

このURLをスマホで開くだけ（`https` なのでGPSが使えます）。

---

## 走行前の準備（スマホ）

1. 上記URLをスマホのブラウザで開く
2. **設定タブ**を開く
   - **ドライバー名**（必須）
   - **車両**（任意）
   - **送信先URL**（スプレッド記録する場合。下の「GASセットアップ」で取得したURL）
   - **コントロールライン**: スタート/フィニッシュ地点で
     - コース左端に立って「**A点=現在地**」
     - コース右端に立って「**B点=現在地**」
     - ※コースを横切る2点。手入力（`緯度,経度`）も可
   - **最小ラップタイム**（誤検知防止。1周にかかる最短秒数の少し下に設定）
3. 「**設定を保存**」
4. **計測タブ** →「**計測スタート**」
5. スマホをダッシュに固定して走行（空が見える向き推奨）

> 1周目はタイム基準の取得に使われ、2周目からタイムが表示されます。

---

## GASセットアップ（スプレッドシート記録する場合のみ）

`../gas/Code.gs` のコードを使います。

1. [Googleスプレッドシート](https://sheets.new)を新規作成
2. メニュー **拡張機能 > Apps Script**
3. 既存コードを消して `gas/Code.gs` の中身を貼り付け → 保存
4. 右上 **デプロイ > 新しいデプロイ**
   - 種類（歯車）: **ウェブアプリ**
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**
   - **デプロイ**
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー
6. スマホ設定画面の「送信先URL」に貼る

これで走行中のラップが自動でスプレッドシートに記録され、**ランキングタブ**でベストタイム一覧が見られます。

---

## 注意

- 走行中は画面を消さないでください（対応端末は自動で点灯維持）
- 電波が無い場所でもGPS計測は動きます（記録の送信のみ電波復帰後に自動再送）
- iPhone / Android どちらもOK（位置情報の許可を求められたら「許可」）
