# GPS Lap Timer — サンプル版（富士スピードウェイ実走版）

プロモーション/デモ用の**安定サンプルアプリ**。2026-08-01〜03に富士スピードウェイで実走検証し、全ラップ検出・記録に成功したバージョンをそのまま固定したものです。

## 公開URL（固定・変更しない）

```
https://evolution-tatsuya.github.io/GPS-World-Lap-Time-Counter/stable/
```

このURLはサンプル用として安定運用します。開発版（`../gps/`）に新機能が入っても、このサンプルは富士稼働時の内容のまま保たれます。

## 特徴（この版の機能）

- スマホ単体・サーバー不要・ネット不要でGPSラップ計測（記録の送信のみ要ネット）
- コントロールライン通過で自動ラップ検出（1周目＝アウトラップとしてLAP1カウント）
- 送信の堅牢化（電波弱でも記録が消えない・未送信の手動一括送信）
- セッション管理（走行ごとに自動区切り＋任意のセッション名）
- Googleスプレッドシートへ自動記録＋ランキング表示

## 使い方

`../gps/README.md` と同じ（設定タブでドライバー名・コントロールライン・送信先URLを入れて計測スタート）。

> ※これはサンプル固定版です。最新の開発版（テレメトリー等の追加機能）は `../gps/` にあります。
