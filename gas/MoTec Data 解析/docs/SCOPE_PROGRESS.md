## 5. 🚨 全機能で守る絶対原則
1. **無いデータは想像で埋めない**（補間・推定・フォールバック禁止。無い時は「データなし」明示）
2. **チャンネル構成は .ld ごとに動的**（有るものだけ表示・計算・比較）
3. **i2 Pro と同じ**（機能・見た目・操作・インポート/エクスポート）

## 6. 未接続時の注意
- `.ld` データ = 外付け `Z34 DATE(1)`（着脱式）。
- i2 ワークスペース = 外付け `SONY_32GU` の `200717`（着脱式、メイン）。
- 実装・検証時は該当ドライブの接続が必要。
