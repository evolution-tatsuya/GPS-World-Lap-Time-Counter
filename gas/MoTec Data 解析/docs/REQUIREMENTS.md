# MoTeC Data 解析アプリ 要件定義書

最終更新: 2026-08-28

---

## 1. プロジェクト概要

MoTeC i2 Pro でロギングした `.ld` データを解析するアプリ。**「i2 Pro と全く同じものを Mac / ブラウザで動くように作る」**ことが最終ゴール。i2 Pro は Windows 専用のため、Mac ユーザーや、i2 を持たないメンバーがデータを確認・解析・共有できるようにする。加えて i2 に無い **AI によるセット変更提案**を独自機能として搭載する。

### 背景・目的
- ユーザー(GAINER TATSUYA)は NISSAN GT-R NISMO GT3 のレースデータエンジニアリングに従事。
- 普段は Windows の i2 Pro を使用。データ比較・解説のスピードを上げ、すり合わせ(セット/ドライビング)を正確にしたい。
- **メインは Windows(i2併用)、時間がある時は Mac でも解析したい**(i2はMacで動かない)。
- 他メンバー(i2 Pro ユーザー含む)とデータチェックする際、このツールで違和感なく使えることが必要。

---

## 2. 🚨 絶対に守る原則（最優先）

### 原則1: 無いデータは想像で埋めない ★最重要
- 車両・センサー・機材構成により `.ld` に含まれるチャンネルは毎回変わる。
- あるworkbookに「ブレーキ圧」タブがあっても、そのセンサーが無い車両のデータでは**表示できないのが正しい**。
- **想像・推測・近似・補間・フォールバック値で "それっぽい値" を絶対に出さない。**
- 理由: セット判断に使うツール。誤った値は車のセッティングを誤らせる**実害**がある。
- 欠損は明示的に「データなし」「〇〇センサー無し」と示す。

### 原則2: チャンネル構成は .ld ごとに動的
- アプリは固定のチャンネル表を持たない。
- 受け取った各ファイルから実在するチャンネルを都度読み取り、**有るものだけ**を表示・計算・比較する。
- 計算チャンネルは元センサーが揃うファイルでのみ成立。
- 別構成の車両同士を重ねる時は共通チャンネルのみ比較可能と示す。

### 原則3: i2 Pro と同じ
- 機能・見た目・操作・インポート/エクスポート・ツール類を可能な限り i2 Pro に一致させる。

## 3. 環境・技術要件

| 項目 | 内容 |
|---|---|
| 実行環境 | 単一HTMLファイル（ブラウザ完結）。Windows/Mac 両対応、OS非依存 |
| 配布ファイル | `MoTeC_Analyzer_standalone.html`（全JSインライン・完全オフライン） |
| オフライン | 解析はすべてブラウザ内で完結。ファイルはPCの外に出ない（チームデータの安全性） |
| AI連携 | Claude API（キー入力時のみ）。数値サマリのみ送信、生 .ld は送らない |
| 開発構成 | `ld_engine.js`(LDパーサ) + `analysis.js`(解析) + `motec_analyzer.html`(UI)。node -e で standalone を生成 |

## 4. データ仕様（実データで確定済み）

### .ld フォーマット
- ヘッダ 0x00 magic=0x40 / 0x08 meta_ptr / 0x0C data_ptr。
- チャンネルメタ = 124バイト固定ブロックのリンクリスト。
- dtype: 0/3/5 いずれも整数(datasize 2/4byte) × scale/dec/mul。**float32型は存在しない**（dtype=5をfloat誤読するとGPS等が壊れる→修正済）。
- 物理値: `phys = (raw / scale) × 10^(-dec) × mul + shift`。

### メタ情報（固定オフセット・全ファイル一貫）
| 項目 | オフセット | 例 |
|---|---|---|
| 日付 | 0x5E | 23/08/2026 |
| 時刻 | 0x7E | 12:27:09 |
| コメント | 0x624 | jung-yasuda set-D new- set-B Rrwing FrARB... |
| 設定ファイル | 0x77D | 264H3_User_Basic_for #26 |
| 車両 | 0xDB4 | NISSAN GT-R NISMO GT3 |

### i2 ワークスペース（メイン = SONY_32GU の `200717`）
- **メインで使う workbook は SONY_32GU の `/MoTeC/i2/Workspaces/200717/` フルワークスペース**（15 workbook + Maths + Track Maps）。
- 最初に渡された Z34 DATE/Workbooks(7個)は ch/ページが少ないので使わない。
- Workbook 構造: `Worksheet > Graphs > Graph(=1グラフ枠) > Traces > Trace(Id="ch名")`。1つの Graph に複数 Trace = 複数ch重ね表示。
- 計算チャンネル: `Maths/User.xml`(自作66ch)・`Brake endless.xml`(制動15ch)。MoTeC式をJSにコンパイルして再現。

---

## 5. マルチユーザー / Workspace（i2 と同じ思想）
- 使う人ごとに見方・計算内容が違う。
- 各ユーザーが自分の Workspace（workbook + 計算ch）をアップロード → 自分好みの環境で使う。
- 設定はブラウザ(localStorage)にプロファイル単位で保存し、切り替える。

---

## 6. 車両・セットアップ前提（AI提案の精度用）
- 車両カテゴリ: **GT/ハコ車（NISSAN GT-R NISMO GT3）**。
- 調整項目: ARB(Fr/Rr)、スプリング/ダンパー、車高/ライドハイト、ブレーキバランス、リアウィング角度、ジオメトリー(トー/キャンバー/キャスター)、ブレーキパッド摩材(μ)、ABS介入、トラクションコントロール。
